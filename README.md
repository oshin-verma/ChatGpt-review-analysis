chatgpt-review-analysis
This project analyzes user reviews of ChatGPT to extract insights about user satisfaction and improvement areas. It includes sentiment analysis, Net Promoter Score (NPS) calculation, and visualization of key trends using Python. The goal is to understand what users love about ChatGPT, identify pain points, and recommend improvements.
Tech Stack
Programming Language: Python 
Environment: Google Colab
Libraries: pandas, matplotlib, seaborn, nltk (Natural Language Toolkit), wordcloud
Key Insights
65% of users expressed positive sentiment in their reviews.
Common concerns: latency issues, hallucinations, and pricing.
Net Promoter Score (NPS): +32, indicating strong user loyalty.
Visualizations reveal that most negative reviews came from early 2023, suggesting improvements over time.
