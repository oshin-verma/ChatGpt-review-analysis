ChatGPT Review Analysis

This project analyzes user reviews of ChatGPT to extract insights about user satisfaction and identify areas for improvement. It includes **Sentiment Analysis**, **Net Promoter Score (NPS)** calculation, and visualization of key trends using Python.  

The goal is to understand what users love about ChatGPT, uncover pain points, and recommend actionable improvements.  

Features
 Sentiment analysis of user reviews (positive, neutral, negative)
 Net Promoter Score (NPS) calculation to measure user loyalty
 Trend visualization (monthly/yearly patterns)
Insights into key user concerns and satisfaction drivers
 Built using Python and interactive Jupyter Notebook

 Tech Stack
Programming Language:** Python  
Libraries:** pandas, matplotlib, seaborn, nltk (Natural Language Toolkit), wordcloud  
Environment:** Google Colab / Jupyter Notebook  

Key Insights
**65% of users** expressed positive sentiment in their reviews.  
 Common concerns: latency issues, hallucinations, and pricing.  
 **Net Promoter Score (NPS): +32**, indicating strong user loyalty.  
 Most negative reviews were from early 2023, showing improvements over time.
